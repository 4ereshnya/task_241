## Файловые системы

### 1. Какие файловые системы вы знаете?
- **Windows:** NTFS, FAT32, exFAT
- **Linux:** ext4, ext3, ext2, XFS, Btrfs, ZFS
- **macOS:** HFS+, APFS
- **Сетевые:** NFS, CIFS/SMB
- **Специальные:** procfs, sysfs, tmpfs

### 2. Классификация файловых систем
- **По назначению:** дисковые, сетевые, виртуальные, специализированные
- **По структуре:** журналируемые (ext4, XFS) и нежурналируемые (ext2, FAT32)
- **По организации:** блочные, объектные

## RAID массивы

### 1. Типы RAID массивов

- **RAID 0** - striping (повышение производительности, без избыточности)
- **RAID 1** - mirroring (зеркалирование)
- **RAID 5** - striping with parity
- **RAID 6** - двойная четность
- **RAID 10** - mirroring + striping

### 6.  Разница
в рейд 0 нет избыточности данных, если один диск капут все данные капут
в рейд 1 данные отражаются на все диски массива 
по скорости:
в р0 - максимальная, данные гоняются по всем дискам сразу.
в р1 - запись как у одного диска. Чтение может быть быстрее.
по месту: р0 - 100% полезного места
р1 - 50% полезного места
