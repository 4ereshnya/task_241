## 2. Что такое общая папка и зачем она нужна?
Общая папка - это каталог, доступ к которому предоставляется нескольким пользователям или компьютерам по сети.  Используется для обмена файлами, совместной работы и централизованного хранения данных.

## 3. Общая папка без пароля, только чтение
```
[milfhntr@host-15 linux]$ sudo mkdir -p /srv/samba/public_ro
[sudo] password for milfhntr:
[milfhntr@host-15 linux]$ sudo chmod 755 /srv/samba/public_ro
[milfhntr@host-15 linux]$ sudo nano /etc/samba/smb.conf
[public_ro]
    path = /srv/samba/public_ro
    browsable = yes
    guest ok = yes
    read only = yes
[milfhntr@host-15 linux]$ sudo systemctl restart smb
```

## 4. Общая папка с паролем, чтение и запись
```
[milfhntr@host-15 linux]$ sudo mkdir -p /srv/samba/private_rw
[milfhntr@host-15 linux]$ sudo chmod 770 /srv/samba/private_rw
[milfhntr@host-15 linux]$ sudo useradd smbuser
[milfhntr@host-15 linux]$ sudo smbpasswd -a smbuser
New SMB password:
Retype new SMB password:

[milfhntr@host-15 linux]$ sudo nano /etc/samba/smb.conf
[private_rw]
    path = /srv/samba/private_rw
    browsable = yes
    valid users = smbuser
    read only = no
[milfhntr@host-15 linux]$

```

## 5. Общая папка **с паролем**, чтение и запись
```
[milfhntr@host-15 linux]$ sudo groupadd smbgroup
[milfhntr@host-15 linux]$ sudo usermod -aG smbgroup smbuser
[milfhntr@host-15 linux]$ sudo mkdir -p /srv/samba/group_full
[milfhntr@host-15 linux]$ sudo chown :smbgroup /srv/samba/group_full
[milfhntr@host-15 linux]$ sudo chmod 770 /srv/samba/group_full
[milfhntr@host-15 linux]$ sudo nano /etc/samba/smb.conf
[group_full]
    path = /srv/samba/group_full
    browsable = yes
    valid users = @smbgroup
    read only = no
```

## 6. разные права для разных групп
```
[milfhntr@host-15 linux]$ sudo groupadd fullgrp
[milfhntr@host-15 linux]$ sudo groupadd rogrp
[milfhntr@host-15 linux]$ sudo groupadd nogrp
[milfhntr@host-15 linux]$ sudo mkdir -p /srv/samba/mixed_access
[milfhntr@host-15 linux]$ sudo chown :fullgrp /srv/samba/mixed_access
[milfhntr@host-15 linux]$ sudo chmod 770 /srv/samba/mixed_access
[mixed_access]
    path = /srv/samba/mixed_access
    browsable = yes
    valid users = @fullgrp, @rogrp
    write list = @fullgrp
    read list = @rogrp
    read only = yes
```
